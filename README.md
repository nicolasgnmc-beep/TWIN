TWIN v2

Archivos:
- index.html
- api/video.js
- manifest.webmanifest
- vercel.json

Variables de entorno en Vercel:
- DID_API_KEY = tu API key de D-ID
- DID_SOURCE_URL = URL pública del presentador/avatar creado en D-ID
- DID_VOICE_ID = opcional (por defecto es-ES-AlvaroNeural)

IMPORTANTE:
DID_API_KEY nunca debe escribirse en index.html.
Después de añadir/cambiar variables de entorno, vuelve a desplegar el proyecto.
